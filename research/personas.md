## 1. 연구별 정리

### 루이 로페즈 기초 — "수순은 엔진이, 나는 이유를"
- **챕터 흐름**: 배경지식(1.e4~3.Bb5까지 한 수씩, 다른 첫 응수는 추천 라인만) → 폰 따는 게 그리 간단하진 않아(4.Bxc6 dxc6 5.Nxe5? Qd4!) → 모피 디펜스(a6의 진짜 이유, b5를 "아껴 두는" 이유) → Open → 폰 구조상의 우위?(익스체인지의 4:3 다수) → 익스체인지 → Closed Main Line → Marshall Attack → Berlin → 베를린 엔드게임 → 슐리만 → 버드 → 워롤 어택(실전 GM 대국 링크) → 안티 마샬 a4 → 9...a5 → 8.h3 → 아르한겔스크 → 8.d4 → 마샬 9.d4 → 피앙케토 → 코지오 → 노르웨이.
- **오프닝의 사상**: 서로 e폰을 "간접적으로" 공격하고 방어한다. 폰을 언제 움직이는지(b5, d6를 숨기는 것)가 전략이다.
- **저자의 관점**: "다짜고짜 수순을 이야기하는 건 엔진이 더 잘 하니까 나는 다른 쪽을 맡겠다." "외워서 뇌 빼고 두지 말고, b5 언제 밀지 생각하고 있으면 됨." 목표는 해명이 아니라 "느낌을 잡는 것". 깊은 변화는 "내 역할이 아니다"라고 끊는다.
- **접근법**
  - 앞쪽 챕터는 한 수 한 수 공들이고, 뒤로 갈수록 사이드라인을 짧게 처리한다("다음 챕터부터는 이렇게 한 수 한 수 힘 넣어서 말 안 함").
  - 수를 물음으로 연다("그럼 백은 어떻게 둘까?").
  - 비교한다(이탈리안 Bc5 대 스패니시 Be7).
  - 엔진 평가와 실전(마스터 7할 무승부, 아마추어에선 흑이 10% 더 이김)을 구분한다.
  - 화살표를 아주 많이 쓴다(첫 챕터 76개).
  - 판 방향을 일부러 뒤집는다(마샬: "어? 왜 보드가 돌아가 있지?").

### 초보를 위한 QGD — "구조가 계획을 정한다"
- **챕터 흐름**: 1.d4 d5 2.c4 e6(d4와 e4 첫 수의 차이부터) → 전형적인 진행 → 엘리펀트 트랩 → 라스커(가장 기본 아이디어라서 먼저) → 오소독스(라스커에서 "살짝 욕심") → 타르타코워 → 안티 타르타코워 → 익스체인지 → 9.Nge2 → 9.Nf3(마이너리티 어택) → 5...c6.
- **오프닝의 사상**: 흑은 갑갑한 진영을 기물 교환(특히 어두운 비숍)으로 푼다. 백은 e4 브레이크를 노리지만 그러면 d4가 약해진다.
- **저자의 관점**: 담담한 교사. 변화를 "기본형 + 변형"으로 쌓는다(라스커를 기준으로 오소독스·타르타코워를 차이만 설명). 반복되는 패턴을 다시 짚는다("계속 나온 패턴이지?" Rc1, Bd3).
- **접근법**
  - 매 챕터의 국면 과제를 한 문장으로 정한다("흑의 초반 목표 중 하나").
  - 왜 안 되는지는 곁가지로 바로 보여준다(9...Nd7?! → 원폰다운).
  - 비유를 쓴다("같은 좁은 집이라면 식구가 적은 쪽이 덜 비좁다").
  - 다루지 않는 것은 명시한다("이 연구에서는 다루지 않음").

### King's Indian Game (heyzac) — "이 수를 둬 보세요"
- **챕터 흐름**: 시작해봅시다(게임북 모드) → 메인라인(수순만).
- **접근법**
  - 게임북 형식이다. 플레이어가 수를 고르면 맞으면 칭찬하고, 틀리면 왜 아닌지 알려준다(1...d5 → "이번엔 인디언으로").
  - 경어체로, 상대의 다음 의도를 예고한다("상대도 흑의 피앙체토를 예측하고 움직일겁니다…").
  - 아직 두 챕터뿐인 미완성 연구다.

### Puzzle Themes (hjkim000) — 전술 사전
- 30개 주제(전진한 폰, 유인, 핀, 포크, 추크추방 등)를 한 챕터에 한 국면씩 담았다. 개념 정의 → 그 개념이 드러나는 한 수 → 왜 되는지 순서다. 공식 연구를 번역한 것이고, 마지막 챕터에 출처와 번역어 선택 이유를 적었다.

### 잉글런드 갬빗 — "폐기물에도 개선의 여지는 있다"
- **챕터 흐름**: Orthodox 메인(6.Bc3??로 유명한 블런더) → 백의 더 강력한 응징(8.Nd5!!, +4.6 / 백 승률 69%) → 퀸 희생 변화("그야… 재미있으니까") → Improved Line(4...d6 "full pawn sacrifice") → 갬빗 거절의 "그 전술" → 하트러브 I·II → 하트러브의 아킬레스건 → 솔러 → 딜레이 솔러 → 나이트 프리무브 트랩 → 런던 시스템?? → 펠벡커 → 스톡홀름 → "졸업생을 위한 대학원 코스"(부다페스트로 이어짐).
- **오프닝의 사상**: 나쁜 걸 알고 쓰는 갬빗이다. 상대가 함정을 아는 수준이면 버리거나 개선형으로 간다.
- **저자의 관점**: 정직하다("좋은 평가를 받을 수는 없는 수"). 그래도 버리지 않고 "왜 안 쓰이는지"를 백의 최강 응징으로 보여준 뒤 개선을 찾는다. 다른 연구와 사상으로 연결한다(던스트-페로네의 반전형, 부다페스트의 원형).
- **접근법**: 함정 → 응징 → 더 강한 응징 → 개선 → 상위 오프닝으로 졸업. 속기 실전 팁(프리무브 트랩)을 넣는다.

### 부다페스트 갬빗 — "갈래 지도"
- **챕터 흐름**: 부다페스트 갬빗?(잉글런드의 발전형) → Nf3이 먼저 나오면 불가능(대비책) → 마디간 갬빗("쓰지 말라고 소개", 왜 구린지) → 아들러 4...Nc6 I·II·III(백의 세 응수 각각) → 4...Bc5 → a5 룩 리프트 → ICBM 패턴 → 파야로비치 → Sample Line → 루빈스타인 → 알레킨 → 알레킨 타르타코워 → 백이 무시한다면? → 백의 빠른 a3.
- **오프닝의 사상**: a5–e1 대각선(Bb4+)으로 폰을 되찾고, a5 → Ra6 → Rh6 룩 리프트로 킹사이드를 친다.
- **저자의 관점**: 한 오프닝의 모든 진입과 회피를 지도로 만든다. 나쁜 변형도 "왜 안 되는지 이해하면 좋다"며 넣는다. 공통 테마(Bb4+ 자원, a3로 막기, Nd3# 패턴)를 갈래마다 다시 짚는다.
- **접근법**: 백의 응수마다 챕터를 하나씩 둔다. 실수 표시가 붙은 흔한 수를 실제 빈도와 함께 짚는다("제일 많이 나오는 a5는 블런더다").

### 노아 갬빗?? — 압축된 엔진 라인
- **챕터 흐름**: 센터 포크 트릭 → 백 최선 → Neg5+ → Ng3 → Ng3-2.
- 해설은 거의 없고 수순이 길다. 숫자가 아니라 강공의 타이밍("지금이 타이밍!", "백 전개가 마무리되기 전에 강공")만 짧게 짚는다. 정리 희생과 체크메이트 수순을 그대로 보여준다.

### 스콜라 메이트 / 파럼 어택 — "편견 뒤집기"
- **챕터 흐름**: 의외로 탄탄한 오프닝(GM 실전 링크) → 뉴비 분쇄기 → (스콜라 메이트 방어법) → 흑의 반격 5.d3?! → 5.Nc3?! → 가장 자주 나오는 5.c3 → 올바른 수 5.Ne2 → 메인 라인 → 8.Bg5 핀 → 총평 → 2...d6 → Kiddie Countergambit → 백 입장에서의 상대법 → Frederiksberg 4...f5!! → Napoleon.
- **오프닝의 사상**: 초반 퀸 출동은 템포를 내준다. 대신 견고하게 정비하면 f3 퀸이 h4–h5 폰스톰의 심장이 된다.
- **저자의 관점**: 통념("막기만 하면 응징")을 데이터로 뒤집는다(2000+에서도 백 승률이 상당하다, Ne2를 두면 57%). 사람들이 실제로 두는 수와 최선을 계속 비교한다("놀랍게도 대부분이 이렇게 둔다. 정말 왜 이러는 건지 난 잘 모르겠는데"). 양쪽 시점(흑의 응징과 백의 올바른 운영)을 다 다룬다.
- **접근법**: 흔한 실수 → 그 응징 → 올바른 수 → 총평. 1·2·3번째로 많이 나오는 수를 순서대로 평가한다.

### 안티 프렌치! 알라핀-다이머 — "기보에서 배운다"
- **챕터 흐름**: 마스터 대국 여러 판(흑 승·백 승·무승부) → 저자 본인의 대국 3판("내 게임에서 같이 배워보자") → 4...f5?! → 그 이후 진행 → 모던 c3 방식 → Common Line → 6...Bd6.
- **오프닝의 사상**: 기물을 다 긁어모아 킹사이드를 공격한다. 대신 백 킹사이드가 의외로 약하다.
- **저자의 관점**: 이론보다 실전이 먼저다. 본인 대국에서 실수를 숨기지 않는다("내 수순은 정교하지 못했다", "킹사이드 올인공격 할 생각에 눈이 멀어서 못 봤지"). 엔진의 Inaccuracy·Mistake 표시와 사람의 판단("주도권을 잡았구나 확신했다")을 나란히 적는다.
- **접근법**: 기보 한 판이 챕터 하나다. 결정적 순간에만 긴 해설을 달고, 놓친 최선수는 곁가지로 보여준다.

### 카로-칸 판타지 — "상대의 계획을 축으로"
- **챕터 흐름**: 판타지 바리에이션 → Classical? / Exchange? / Advance?(기존 변화마다 "Bf5를 어떻게 방해하나"로 다시 보기) → Fantasy! → 3...dxe4 메인 → c3 → 흑의 대응: 프렌치로 전환 → 4.Bd3 1·2 → 4.Nc3 Bb4 1·2 → 4...Qb6 포이즌드 폰 → 4...Qb6 메인 → 4.Nc3 메인 → 3...e5!? → Qb6을 섞고 dxe4 → 3...g6 1·2(백 시점) → 정리와 트랩 → 4...Nf6? → 4.Ne2 → 5.Qd3 → 5...Be6 ×3 → 마로치 갬빗 ×2 → 3...e6 큰 불균형.
- **오프닝의 사상**: 카로칸의 핵심(Bf5 전개, 전개에서 어떤 문제도 갖지 않는다)을 정면으로 막는다. 그래서 "카로칸스러운 게임이 나오지 않는" 안티 오프닝이다.
- **저자의 관점**: 기초부터 다시 짚는다("지루해도 넘어가지 말기를"). 백 시점과 흑 시점을 다 보고, 추천과 비추천을 분명히 밝힌다("4.Bd3을 나는 권하지 않음", "내가 권하는 수법"). 가성비도 따진다.
- **접근법**: 한 축(Bf5)으로 모든 주요 변화를 다시 해석한 뒤 본론에 들어간다. 사람 승률과 엔진 평가가 엇갈리는 지점(60%가 넘는 흑 승률)을 짚는다.

### 던스트-페로네 갬빗 — "사이드라인의 끝까지"
- **챕터 흐름**: 이란? → 2...d4 → 3...c5 → 3...Nc6 → 2...Nc6 → 2...e5 → 3...Nf6 → 3...Bf5 → Main Line → 잉글런드 하트러브(반전형) → 4...Nc6 → 이중 폰 희생 ×4 → 데 슈메트(흑으로) → 저자 본인의 대국.
- **오프닝의 사상**: 열린 d파일을 장악하고, 퀸사이드로 캐슬링한 뒤 룩 배터리를 쌓는다.
- **저자의 관점**: 거절, 회피, 수락을 모두 덮는다. 흑이 피할 수 있다는 걸 인정하면서도("백은 응징 수단이 없다") 그 대가가 선공 이점을 돌려주는 것임을 밝힌다. 흑백을 뒤집은 같은 셋업을 연결한다.

### 블랙번-실링 갬빗 — "함정의 앞과 뒤"
- **챕터 흐름**: 시작 포지션 → 눈을 크게 떠라(국면 파악부터) → 무시 바리에이션 → 앱센트 선 트랩 → 4.Nxe5 블랙번 트랩 → 메인 5...d6 ×2 → 5...Bc5?? → 4.Nxd4 이후 흑 최선 → 5...c6 메인들 → 6.Re1!(진짜 메인이라고 봄) → 6.Qh5 → "그럼 4.Nxe5는 블런더 아닌가?" → 5.Bxf7+!! I·II.
- **오프닝의 사상**: 함정에 기대는 갬빗이다. 함정이 무산된 뒤를 준비하지 않으면 전개가 늦어 진다.
- **저자의 관점**: "수순을 입에 떠 먹이는 건 엔진도 할 수 있으니, 포지션을 파악해 보자." 함정을 거는 쪽과 당하는 쪽을 둘 다 보고, 마지막에 상식을 뒤집는다(블런더로 알려진 4.Nxe5에도 5.Bxf7+!!가 있다). 왜 무식한 공격이 통하는지 이유 세 가지를 든다.
- **접근법**: 함정 → 함정 회피 후 메인 → 흑의 최선 → 백의 진짜 최선 → 반전.

---

## 2. 반복해서 보이는 기법

1. **이유 우선, 수순은 압축.** "엔진이 더 잘한다"는 전제로 사람만 할 수 있는 것(왜, 언제, 무엇을 위해)을 맡는다.
2. **물음으로 챕터와 수를 연다.** 챕터 이름도 물음이다("Clasical?", "그럼 4.Nxe5는 블런더 아닌가?", "백이 아예 무시한다면?").
3. **기본형 + 변형.** 기준 변화를 하나 정하고, 나머지는 차이만 설명한다(라스커 → 오소독스, Bf5 축).
4. **흔한 수 대 최선수.** 사람들이 실제로 두는 수, 그 수의 결과, 진짜 최선수를 나란히 놓는다.
5. **엔진 평가 대 사람의 관점.** 수치는 같아도 실전에서는 한쪽이 훨씬 편하다는 걸 구분해서 말한다("엔진은 0.0, 사람 기준으로는 흑이 훨씬 유리").
6. **함정 → 응징 → 개선.** 함정은 반드시 응징과 함께 보여주고, 응징을 피하는 개선형으로 이어간다.
7. **양쪽 시점.** 같은 오프닝을 쓰는 쪽과 상대하는 쪽 둘 다 다룬다(판 방향도 바꾼다).
8. **범위를 선언한다.** 다루지 않는 것은 "내 역할이 아니다" / "이 연구에서는 다루지 않음"으로 끊는다.
9. **연구끼리 연결한다.** 반전형, 발전형, 상위 오프닝으로 링크한다(잉글런드 → 부다페스트, 하트러브 ↔ 던스트-페로네).
10. **판 위의 그림.** 화살표와 원이 해설의 절반이다(챕터당 수십 개).
11. **기보.** 마스터 대국과 본인 대국을 복기하고, 실수를 숨기지 않는다.

## 3. 장기 연구용 페르소나 (초안)

lichess와 달리 우리에겐 **사람 대국 통계(마스터 DB, 승률)가 없다.** "흔한 수", "승률 60%" 같은 말은 할 수 없다. 사이트의 대국이 쌓이면 그때 쓴다. 근거는 엔진 분석 하나뿐이니, 페르소나는 **관점과 서술 방식**으로만 나눈다.

| # | 페르소나 | 원형 | 관점 | 연구 방식 | 챕터 이름 예 |
|---|---|---|---|---|---|
| A | **이유를 묻는 선생** | 루이 로페즈, QGD | 수순은 엔진이, 나는 "왜"를 | 시작 포진부터 한 수씩, 수마다 그 수가 막는 것과 여는 것. 기준 변화를 정하고 나머지는 차이로 | "왜 첫 수는 졸인가" |
| B | **구조주의자** | QGD | 포진(형태)이 계획을 정한다 | 포진별 약점, 급소, 브레이크 칸(장기에선 궁성, 포 길, 차 길)을 먼저 정하고, 변화를 "이 형태의 과제를 어떻게 푸나"로 비교 | "면포 다음, 초의 과제" |
| C | **함정 사냥꾼** | 블랙번-실링, 잉글런드, 노아 | 함정은 응징과 한 세트다 | 함정 → 걸리는 수 → 응징 → 함정을 건 쪽의 개선. 엔진이 찾은 날카로운 수순 | "ab7??의 대가" |
| D | **편견 뒤집기** | 파럼 어택, 블랙번 마지막 챕터 | 나쁜 수라던 수가 정말 나쁜가 | 엔진 평가가 낮은 첫 수나 응수를 끝까지 따라가, 어디까지 버티는지와 어디서 무너지는지 | "정말 둘 수 없는 수인가?" |
| E | **안티 이론가** | 판타지 카로칸 | 상대의 핵심 계획을 막는 쪽에서 본다 | 한 포진의 핵심 계획(예: 면포, 진마)을 하나 정하고, 상대의 응수들을 "그 계획을 어떻게 방해하나"로 재해석 | "면포를 늦추는 세 가지 방법" |
| F | **지도 제작자** | 부다페스트, 던스트-페로네 | 갈래를 빠짐없이 | 한 국면에서 가능한 모든 합리적 응수를 펼쳐 지도를 만든다(수평). 각 갈래는 짧게, 어디로 이어지는지 연결 | "3수째의 다섯 갈래" |
| G | **복기하는 기사** | 알라핀-다이머 | 실전에서 배운다 | 사이트에서 둔 대국(공개 기보)을 오프닝 관점에서 복기. 결정적 순간과 놓친 최선. *대국 기보 사용 기준은 따로 정해야 함* | "어느 대국의 10수" |
| H | **전술 사전** | Puzzle Themes | 수법 하나에 국면 하나 | 멍군, 포 다리 끊기, 궁 몰이, 양수겸장 같은 수법을 오프닝 변화 속에서 찾아 한 챕터에 하나씩 | "포 다리 끊기" |

**날짜별 교대**
- 매일 페르소나 하나를 정해서 그 관점으로 조사하고 쓴다(교대 순서와 규칙은 미정).
- 같은 주제(예: 귀마 대 귀마)를 여러 페르소나가 번갈아 보면 수직(A, C, D)과 수평(B, E, F)이 자연스럽게 섞인다.
- 연구 주제는 시작 포진 조합(귀마 대 귀마, 양귀마 대 귀마, 원앙마 대 귀마, …)부터 시작한다.
- 이름 붙은 갈래는 태그로 묶는다(정형포진, 최국수포진 등).

**말투**
- AbsentSun의 반말이나 인터넷체를 그대로 따라 하지 않는다. 페르소나마다 짧은 어조 지침만 둔다.
- 예: 선생은 "~다"체로 담백하게, 함정 사냥꾼은 짧고 단정하게.

**지금 뷰어로 안 되는 것**
- 게임북(문답형, heyzac): 플레이어가 수를 맞히는 모드.
- 챕터별 판 방향 지정(마샬처럼 한의 시점으로 보기).

필요하면 `[Orientation "han"]`, `[Mode "quiz"]` 같은 태그로 추가할 수 있다.
